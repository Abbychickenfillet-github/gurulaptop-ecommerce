# 聊天記錄問題總結清單

**建立時間**: 2025年9月10日  
**目的**: 記錄所有聊天相關問題的解決方案和經驗總結

## 主要問題與解決方法

### 1. **SQL 資料庫遷移問題**
- **問題**: MySQL 到 PostgreSQL 遷移時出現日期時間格式錯誤
- **解決**: 將 `'0000-00-00 00:00:00'` 改為 `NULL`，移除 `created_at` 欄位讓 `DEFAULT NOW()` 自動生效
- **關鍵**: 理解 PostgreSQL 約束檢查順序，避免在 INSERT 中明確指定 `NULL` 給 `NOT NULL` 欄位

### 2. **認證系統問題**
- **問題**: JWT token 無法被前端讀取，導致登入狀態錯誤
- **解決**: 將 cookie 的 `httpOnly: false`，確保前端可以讀取 token
- **關鍵**: 檢查環境變數 `ACCESS_TOKEN_SECRET` 是否正確設置，確保 `credentials: 'include'` 在 fetch 請求中

### 3. **圖片顯示問題**
- **問題**: 產品圖片無法顯示，頭像圖片不一致
- **解決**: 統一使用 `auth.userData.image_path`，移除本地狀態，添加 `key` 屬性強制重新渲染
- **關鍵**: 資料庫 `product_img` 表遷移不完整，需要完整遷移資料

### 4. **效能優化問題**
- **問題**: 認證邏輯重複渲染，圖片切換效能差
- **解決**: 使用 `useCallback` 和 `useMemo` 優化函數和計算，使用索引而非陣列重排
- **關鍵**: 理解 React 優化時機，避免不必要的重新創建

### 5. **架構問題**
- **問題**: `ChatRoom` 物件錯誤放置在 `configs/pgClient.js`
- **解決**: 將業務邏輯移動到 `models/ChatRoom.js`，恢復 `configs/pgClient.js` 為純配置檔案
- **關鍵**: 遵循 MVC 架構原則，配置與業務邏輯分離

### 6. **Group 路由問題**
- **問題**: `column "pending" does not exist` 錯誤
- **解決**: 檢查資料庫結構，修正 SQL 查詢中的欄位名稱
- **關鍵**: 確認 MySQL 到 PostgreSQL 遷移時所有欄位都正確對應

### 7. **WebSocket 連線問題**
- **問題**: 開發環境連接到 Zeabur 而非本地
- **解決**: 檢查環境變數設置，確保開發環境使用本地 WebSocket 連線
- **關鍵**: 區分開發和生產環境的連線配置

## 通用解決原則

1. **資料庫遷移**: 檢查所有欄位名稱、資料類型和約束條件
2. **認證系統**: 確保 token 可以正確傳遞和讀取
3. **圖片處理**: 統一資料來源，避免本地狀態與全域狀態衝突
4. **效能優化**: 適當使用 React 優化 hooks
5. **架構設計**: 遵循 MVC 原則，保持關注點分離
6. **環境配置**: 確保開發和生產環境配置正確

## 預防措施

- 在資料庫遷移前先測試所有 SQL 語句
- 使用 TypeScript 或 JSDoc 提供更好的類型檢查
- 定期檢查架構是否符合最佳實踐
- 在部署前進行完整的本地測試
